PART OF SENTENCE ADVENTURES COLLECTION

Deploy the parent Sentence-Adventures-Collection folder. Its index.html is
the shared landing pad. The Landing pad links return to that shared page.

TEACHER VOICE OVERRIDE
Choose Teacher voice on the landing page, profile chooser or activity header.
Enter 259, then choose Enable voice or Disable voice. The control locks again
after every change and whenever the dialog closes. Both automatic reading and
Listen obey this setting; disabling also stops speech already playing.
The preference is saved for this adventure in this browser, separately from
the other adventure, and applies to every school-supply profile and both levels.
Voice starts enabled. Enabling it does not automatically start speaking; the
next Listen press or next question will read aloud. Stop always stays available.
The code is a classroom override for a static activity, not account security.

PLAY AND ASSESSMENT
A and AA each contain 100 questions, with three endings and one correct answer.
Choose the same school-supply picture to continue saved work. Teacher tools
export a real .xlsx workbook with progress, attempts, hints and listens.
Scores, balloons and the existing browser progress keys are preserved.
The activity fits one screen. Small portrait screens switch between Picture
and Read & answer. Local storage belongs to the site address and browser;
hosting at a new address starts a separate set of progress and voice settings.

ARTWORK
The deployment package includes 100 optimized WebP scene illustrations.
ARTWORK.json records source provenance. The two revised basketball scenes in
Adventures 2 vary the repeated pairing and retain the question's visual clues.
IMAGE-REVISIONS.json in Adventures 2 records the exact built-in Image Generation
prompts used for those revisions. Original PNG source art is excluded from the
deployment package to keep uploads small.
