SENTENCE ADVENTURES COLLECTION

Open index.html to choose Sentence Adventures or Sentences Adventures 2.
Each Start adventure button opens that activity's A/AA and school-supply chooser.
Use Landing pad to return and choose the other adventure.

DEPLOY
Upload this entire unzipped folder, with index.html at its root.
Keep both adventure subfolders together. There is no build command.
For Netlify, the publish directory is . (this folder).
All code, images, voice controls and Excel export files are included.

TEACHER VOICE
Inside either activity, choose Teacher voice, enter 259, and enable or disable.
Each adventure remembers its own voice setting and progress in this browser.
The teacher code and all existing questions, pictures and assessments remain.

Both activities use one-screen layouts. The shared landing pad also fits
laptops, tablets and phones without page or internal scrolling.
